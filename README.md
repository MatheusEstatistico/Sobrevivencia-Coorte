# Sobrevivencia-Coorte
A Análise de Sobrevivência em Coorte Clínica é uma abordagem estatística essencial para estudar o tempo decorrido até a ocorrência de um evento de interesse (como óbito, cura ou recidiva) em um grupo de pacientes com características comuns. Este repositório apresentará essa análise para dados de [] do SUS.
